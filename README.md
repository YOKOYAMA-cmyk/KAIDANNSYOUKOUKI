# KAIDANNSYOUKOUKI
# 新型階段昇降機 開発プロジェクト

## プロジェクト概要

本プロジェクトは、直線階段昇降機および曲線階段昇降機の新型制御基板開発と、それに伴うソフトウェア開発を行うための開発管理リポジトリです。

現行機種で使用している電子部品の一部が廃番となったことを背景に、新規制御基板の開発が必要となりました。

これに伴い、制御ソフトウェアの刷新も行います。

また、直線階段昇降機については、本体構造の見直しも同時に実施し、薄型化および機種構成の整理を進めます。

本リポジトリでは、今後の開発内容、仕様、課題、進捗状況を随時整理・管理していきます。

---

## 開発対象

今回の開発対象は、以下の2機種です。

### 直線階段昇降機

直線階段昇降機については、基板開発および本体開発を行います。

主な開発内容は以下の通りです。

- 新基板開発
- ソフトウェア開発
- 本体構造の見直し
- 機種構成の整理・絞り込み
- 折り畳み時の本体幅を24cmから20cmへ薄型化

### 曲線階段昇降機

曲線階段昇降機については、基板開発を行います。

本体構造については、現行機をそのまま使用する方針です。

主な開発内容は以下の通りです。

- 新基板開発
- ソフトウェア開発
- 現行本体への適合確認
